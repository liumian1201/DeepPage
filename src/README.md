# 📑 DeepPage 浏览器起始页扩展 - 开发文档

## 1. 项目概述

* **项目名称** ：DeepPage
* **项目类型** ：Chrome 浏览器自定义新标签页扩展（New Tab Override Extension）
* **核心定位** ：基于 FVD Speed Dial 视觉风格的模块化、可定制、支持云同步的极简高效起始页。
* **开发技术栈** ：HTML5, CSS3 (Grid/Flexbox), JavaScript (Vanilla JS), Chrome Extension API (Manifest V3)
* **支持主题** ：浅色模式 / 深色模式切换

## 2. 功能需求说明书

### 💪 核心功能模块

1. **多功能搜索引擎搜索框**
   * 置顶居中显示，搜索框最左侧显示当前搜索引擎图标。
   * 默认支持 **Google** 和 **百度** 两种搜索引擎，后续可扩展。
   * 在设置面板中可切换搜索引擎，切换后图标同步更新。
   * 输入关键词后回车直接跳转对应搜索引擎结果页。
2. **大块快捷导航（FVD 风格 Speed Dial）**
   * **视觉样式** ：采用类似 FVD 的大方块卡片（CSS Grid 布局），卡片包含网站图标（Favicon）或自定义图片、文字背景、网站名称。
   * **图标获取策略** ：优先自动抓取目标网站的 `favicon.ico` 作为默认来源；同时保留用户手动上传自定义图片的入口。
   * **动态交互** ：
     * 支持用户手动【添加】、【删除】、【修改】网址和名称。
     * 支持 **拖拽排序**（纯鼠标事件实现），自由调整卡片位置。
   * **布局配置** ：
     * 列数 Slider（2-12，默认 5），Grid 动态计算列宽
     * 卡片宽度 Slider（100-400px，默认 270）
     * 卡片高度 Slider（80-400px，默认 270）
     * 卡片圆角 Slider（0-50px，默认 14）
     * ↺ 一键恢复默认尺寸
     * 开关控制：+ 添加按钮、卡片上方图标、卡片上方标题
   * **右键菜单** ：
     * 卡片右键：【打开】【复制 URL】【编辑】【删除（红色）】
     * 空白处右键：【添加】【刷新】【🖼️ 下一张壁纸】【设置】【🔒 锁定】【🔓 解锁】
   * **平滑效果** ：鼠标悬停（Hover）时有轻微放大或阴影加深效果。
3. **多功能信息看板（带独立功能开关）**
   * **时间显示** ：大字号 24 小时制数字时钟。
   * **农历信息** ：显示当天的中国传统农历日期（需引入轻量级农历转换 JS 库）。
   * **天气预报** ：支持 4 种数据源 — Open-Meteo（默认，免费免 Key）、和风天气、OpenWeatherMap、自定义 API。
   * **组件控制中心** ：提供设置面板（右上角齿轮图标 → 点击弹出），每个项目（时间/农历/天气）都有一个 Toggle 开关，用户可自行决定是否在主页显示。

### 🎨 视觉与外观设计

* **风格参照** ：整体向 FVD Speed Dial 看齐，大卡片感，布局错落有致，支持响应式（根据屏幕大小自动调整每行卡片数量）。
* **深色模式** ：支持浅色 / 深色模式切换，可通过设置面板手动切换，也可跟随系统主题自动切换。
* **背景壁纸系统** ：
  * 模式 A：接入 API 每日自动更新（如 Bing 每日壁纸或 Unsplash 极简壁纸）。
  * 模式 B：用户手动设定图片 URL 或上传本地壁纸（IndexedDB 存储，无大小限制）。
* **设置面板交互** ：
  * 入口：右上角齿轮 ⚙️ 图标。
  * 形式：点击后直接弹出设置面板（浮层/抽屉式），包含搜索引擎切换、卡片列数、组件开关、天气 API 配置、壁纸模式、主题模式等。

### 💾 数据存储与同步

* **轻量配置**（快捷导航、设置、外观参数）→ `chrome.storage.sync`，Google 账号跨设备自动同步
* **大文件图片**（壁纸、卡片图标）→ **IndexedDB**（`DeepPageImages` 数据库），本地存储，无大小限制，不参与同步

## 5. 补充技术约束与防坑规范

### 🔒 Manifest 权限声明

* 必须在 `manifest.json` 中声明 `"permissions": ["storage", "unlimitedStorage"]` 权限。
* 必须在 `"host_permissions"` 中白名单外部 API 域名：
  * 和风天气：`https://devapi.qweather.com/*`、`https://geoapi.qweather.com/*`
  * 必应壁纸：`https://www.bing.com/*`
  * Open-Meteo：`https://api.open-meteo.com/*`、`https://geocoding-api.open-meteo.com/*`
  * OpenWeatherMap：`https://api.openweathermap.org/*`
* 天气请求通过 `background.js` Service Worker 代理。
* CSP：`script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' http: https: data: blob:; connect-src https:`

### 💾 存储方案

* `chrome.storage.sync`：轻量配置（URL 文本、开关状态），总配额约 100KB，跨设备自动同步
* **IndexedDB**（`DeepPageImages`）：用户上传的图片（壁纸、卡片图标），Blob 直存无大小限制，不参与同步
* `manifest.json` 已声明 `unlimitedStorage` 权限

### 🖼️ Favicon 兜底机制

* 若 Favicon 获取失败（网络错误、404、跨域等），自动取网站名称**第一个字符**，生成**纯色背景文字卡片**占位
* 背景颜色基于网址字符串哈希，同一网站在不同设备上展示颜色一致

## 6. 高级定制与数据管理

### 🎨 外观配色模块（Appearance Settings）

通过细粒度调整页面元素的色彩和文本大小，所有配色和滑块数值实时绑定 CSS 变量，实现**即时无刷新预览**。

* **背景颜色（Background Color）**
  * UI 控件：Color Picker（颜色选择器）。
  * 技术逻辑：修改 `--bg-primary` 变量。当用户未指定背景图片或图片加载失败时，作为兜底的纯色背景。

* **背景图片**
  * UI 控件：Text Input（URL）+ 📁 上传按钮
  * 技术逻辑：URL 直接应用；上传走 IndexedDB blob 存储，不转 base64
  * 存储策略：URL 文本 → `chrome.storage.sync`；文件 → IndexedDB (`DeepPageImages`)

* **卡片背景色（Card Background Color）**
  * UI 控件：Color Picker。
  * 技术逻辑：控制 Speed Dial 卡片的背景色，绑定 `--bg-card` 变量。

* **卡片文字颜色（Card Text Color）**
  * UI 控件：Color Picker。
  * 技术逻辑：控制卡片内网站名称的文字颜色，绑定 `--text-on-card` 变量。

* **卡片字体大小（Card Font Size）**
  * UI 控件：Slider（范围 `12px - 24px`，带数值实时显示）。
  * 技术逻辑：动态调整卡片名称字号大小，绑定 `--card-font-size` 变量。

### 📐 卡片尺寸与网格布局

自由定义卡片尺寸和网格列数，所有滑块即时预览。

* **每行列数** — Slider（2-12，默认 5），JS 动态设置 `grid-template-columns: repeat(N, Wpx)`
* **卡片宽度** — Slider（100-400px，默认 270），绑定 `--card-width`
* **卡片高度** — Slider（80-400px，默认 270），卡片总高度 = 头部 + 缩略图，绑定 `--card-height`
* **卡片圆角** — Slider（0-50px，默认 14），绑定 `--card-radius`
* **↺ 恢复默认** — 一键重置为 270×270

> 注：已移除预设尺寸（小/中/大）和卡片形状（正方形/长方形/圆形），统一为自由宽高控制。

### 💾 数据管理模块（Data Management）

配置数据（卡片/设置）和图片库（壁纸/图标）分开存储，需分别导出导入。

* **导出配置（Export Config）**
  * 读取 `chrome.storage.sync` → 下载 `*_Config.json`
* **导入配置（Import Config）**
  * 选择 JSON 文件 → 校验 → 覆盖 storage → 刷新页面
* **导出图片库（Export Images）**
  * 读取 IndexedDB 所有 Blob → 转 base64 → 下载 `*_Images.json`
* **导入图片库（Import Images）**
  * 选择 JSON 文件 → 解析 base64 → 写回 IndexedDB → 刷新页面
* **重置全部（Reset All）**
  * 二次确认 → 清除 `chrome.storage.sync` + 删除 IndexedDB 数据库

> 跨电脑还原顺序：先导入配置 JSON → 再导入图片库 JSON → 刷新。

  * ❌ 禁止拖拽排序
  * ❌ 隐藏编辑/删除按钮
  * ❌ 隐藏 + 添加按钮
  * ❌ Ctrl+N 被拦截

  * ✅ 右键菜单正常（编辑/删除选项隐藏）

### 🌤️ 天气系统

支持 4 种数据源，通过 Service Worker 代理请求。

| API | 需要 Key | 免费额度 | 缓存间隔 |
|-----|---------|---------|---------|
| **Open-Meteo**（默认） | ❌ | 10,000次/天 | 15分钟 |
| 和风天气 | ✅ | 1,000次/天 | 30分钟 |
| OpenWeatherMap | ✅ | 60次/分钟 | 20分钟 |
| 自定义 API | 取决于你 | — | 30分钟 |

* **坐标获取**：城市名 → 地理编码 API → 缓存坐标；未设置城市则默认北京
* **缓存机制**：`chrome.storage.local` 存储，刷新间隔内复用；API 失败时降级使用过期缓存
* **设置面板**：下拉切换 API → 显示限制说明和获取链接 → 可调刷新间隔（5-120分钟）→ 实时缓存状态

### 🖱️ 拖拽排序

纯鼠标事件实现（mousedown/mousemove/mouseup），不依赖浏览器原生 Drag API。
* 按住卡片拖动超过 5px 激活
* 半透明幽灵跟随鼠标
* 目标卡片高亮（drag-over 虚线边框）
* 松手时根据鼠标在卡片左/右半判断插入位置
* 按钮区域（编辑/删除）不触发拖拽

### 📂 分组管理（第 7 阶段）

左侧固定指示器，鼠标滚轮切换分组。搜索栏和底部看板固定不变，仅卡片区域切换。

* **数据结构**：`groups: [{id, name, cards:[...]}, ...]` + `activeGroup: index`
* **指示器**：左侧居中固定，显示圆点（● 当前组 / ○ 其他组）+ 底部 ＋ 新建按钮
* **交互**：
  * 点击圆点切换分组
  * 鼠标滚轮循环切换
  * 右键圆点 → 重命名 / 删除（至少保留 1 组）
  * 切换时卡片区淡入淡出过渡
* **迁移**：旧版 `speeddials` 数据自动迁移至默认「常用」分组
* **锁定**：分组切换不受锁定影响

### 🖼️ Bing 壁纸增强

一次拉取最近 8 天壁纸，支持浏览和切换。

* **◀ ▶ 导航**：页面右下角浮动按钮 + 右键菜单「🖼️ 下一张壁纸」
* **版权信息**：右下角显示 `3/8  山间晨雾，黄山，安徽`
* **UHD 4K**：开关启用后替换为超高清壁纸 URL
* **区域切换**：中国/美国/日本/德国/英国/法国，不同区域壁纸不同
* **刷新间隔**：滑块 1-24 小时（默认 6 小时），关闭自动刷新后始终用缓存
* **立即刷新**：强制重新拉取 Bing 最新壁纸
* **缓存**：`chrome.storage.local` 存储全部 8 张，区域切换时重新拉取
